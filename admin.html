No edit access

Add a score

Type the player’s name — pick an existing one to add to their total, or type a new name to create them.

Spreadsheet

Every player, one row each. Click a cell, type, press Tab or Enter — it saves straight to the live board. These are totals, so typing 40 makes their score 40.

Copy the cells straight out of Excel or Google Sheets and paste here. A header row is ignored. Names that already exist are updated rather than duplicated, so you can paste the same sheet as many times as you like.

Checking…
Sheet link & advanced

Only https://docs.google.com/ links are accepted. To use a different sheet, take its ID from the address bar and put it in https://docs.google.com/spreadsheets/d/<ID>/export?format=csv&gid=0.

If it says the sheet isn't shared

Open the sheet → Share → under General access switch Restricted to Anyone with the link, leave the role as Viewer → Done. Viewer is enough: the server only ever reads it, and only you can edit it.

Recent entries

Every score you’ve entered, newest first. Edit fixes a typo; delete removes it from that player’s total.

Players

Rename fixes spelling everywhere. Deleting a player removes them and all of their scores from the board.

Event settings

These show on the public board. Changes appear on everyone’s screen instantly.

Clear the board

Wipes every player and score — use it once after practising, before day one starts.

Checking your access…

Sign in

Only accounts on the admin list can change scores. Everyone else can view the board but not edit it.

First time? Use Create the admin account — the very first account created becomes the admin automatically.

No edit access

You’re signed in, but this account isn’t on the admin list, so it can’t change scores. Send the ID below to whoever runs the board to be added.

Add a score

Type the player’s name — pick an existing one to add to their total, or type a new name to create them.

Recent entries

Every score you’ve entered, newest first. Edit fixes a typo; delete removes it from that player’s total.

Players

Rename fixes spelling everywhere. Deleting a player removes them and all of their scores from the board.

Event settings

These show on the public board. Changes appear on everyone’s screen instantly.

Clear the board

Wipes every player and score — use it once after practising, before day one starts.
